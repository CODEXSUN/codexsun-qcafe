# Interface Topology Overlay

Use the Interface Topology Overlay (ITO) for every user-facing feature workspace.

Use **Topology Inspection** as the user action.

Add a stable numbered label for each major workspace region and interactive block.

Show labels as a transparent glass layer. Do not mix labels with product content.

Add an icon-only switch in the inspector to show or hide the numbered labels.

Give each label a name, scope, and short purpose in the topology registry.

Use an independent floating Topology Inspection control at the lower-right edge, above Notifications.

Keep labels selectable. Selecting a label must copy its section name, open the inspector, and select the matching registry item.

Add a Boundary Highlighter for complex layout work. The highlighter must show a 2px purple inner ring for the selected mapped section.

Update the registry whenever feature sections change.

Run focused UI verification after a topology change.
