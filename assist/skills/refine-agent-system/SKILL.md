# Refine the agent system

Read `assist/rules/agent-learning-rules.md` before changing agent behavior.

Collect a failing or weak run with its acceptance criterion.

Write a scoped proposal. Include the evidence, risk, and expected effect.

Do not apply the proposal without review. Re-run the relevant evaluation after acceptance.

Keep model-provider code behind the framework adapter.
