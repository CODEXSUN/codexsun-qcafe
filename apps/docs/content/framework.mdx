# Framework Kernel

The Framework Kernel owns module validation, dependency ordering, explicit service bindings, application startup, shutdown, and startup rollback.

## Boundary

The kernel is tenancy-neutral. It does not own product behavior, tenant context, tenant storage, or tenant authorization.

The Platform host selects modules, binds adapters, and exposes transport endpoints. Applications own their business rules, data, routes, workers, and workspaces.

## Execution

The Framework defines lifecycle hooks and validated manifests. Execution providers run isolated application instances with their own processes, networks, volumes, limits, health checks, and logs.

Generated or untrusted code must run through an approved isolated execution provider. It must not run on the host.
