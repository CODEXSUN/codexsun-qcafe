# Zetro Mobile

Zetro Mobile will use Expo with React Native.

Expo supports Android and iOS from one TypeScript project. It supports secure storage, push notifications, camera and file input, offline SQLite, and device registration. EAS Build can produce iOS artifacts from Windows. iOS distribution requires an Apple Developer account and TestFlight.

## Mobile responsibilities

- Show live task and deployment status.
- Assign and review tasks.
- Receive DCS device messages.
- Cache recent tasks and chats for offline use.
- Sync queued operations after connectivity returns.

The mobile application must use Platform Identity, DCS, Chat, and Task public APIs. It must not copy desktop identity code or access database tables directly.
