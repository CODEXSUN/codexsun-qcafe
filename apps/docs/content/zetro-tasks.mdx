# Zetro and Tasks

Zetro accepts a human request, writes a machine-ready plan, chooses approved agents, and collects evidence. The AI Task System owns task state, acceptance criteria, approvals, and result history.

```mermaid
flowchart LR
  Prompt[Human request] --> Zetro
  Zetro --> Normalize[Machine-ready request]
  Normalize --> Plan[Plan and acceptance criteria]
  Plan --> Task[AI Task System]
  Task --> Agents[Isolated agent containers]
  Agents --> Evidence[Evidence and results]
  Evidence --> Review[Zetro review]
  Review --> Approval{Approval required?}
  Approval -->|Yes| Operator[Manual approval]
  Approval -->|No| Complete[Complete]
  Operator --> Complete
```

Agent runtimes can propose changes. They cannot change rules, prompts, learned guidance, or code without review.
