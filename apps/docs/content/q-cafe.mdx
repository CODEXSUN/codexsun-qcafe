# Q Cafe

Q Cafe is a standalone restaurant application for point of sale, kitchen tickets, inventory, and bookings.

## Ownership

Q Cafe owns its web workspace, API, SQLite database, migrations, Windows desktop runtime, and Docker runtime. The Platform registers the application URL. Shared UI and topology tools use public package exports.

## Current workflows

- Point of sale creates orders and kitchen tickets with server-owned menu prices.
- Kitchen tickets move through queued, preparing, ready, and served states.
- Inventory records manual adjustments and their reasons.
- Bookings reserve tables and reject overlapping reservations.

## Runtime

The local API uses port `4180` and the web workspace uses port `5180`. The Windows desktop package has its own Tauri shell and app-owned database location. Q Cafe does not share restaurant records or operator keys with Chat or Zetro.

Payments, tax invoices, printing, recipe consumption, menu administration, booking cancellation, and multi-user permissions are not implemented.
