# Startup and IoT

Startup settings control local browser preferences for application and workspace features.

## Startup preferences

The Platform stores startup preferences in browser storage. Users can enable or disable available applications and selected workspace features without changing server configuration.

## IoT control panel

The optional IoT control panel lets a user add normalized capability tags to registered applications. Typical tags include `iot`, `sensors`, `telemetry`, and `automation`.

The tags describe local configuration only. Device connections, commands, and authorization remain the responsibility of an application provider. Turning off the control panel retains saved tags.
