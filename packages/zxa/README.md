# ZXA

## Purpose and features

**ZXA**

### Why this module exists

Run model-provider requests in an isolated Docker runtime.

### Features and boundaries

Codex, Gemini, and OpenCode connections; provider APIs; parallel requests; image metadata; controlled CLI updates; agent-definition staging. Model image understanding needs provider configuration. See docker/README.md.

### Integration

Use this module's public exports or registered API contracts. Do not read another module's tables or import its private implementation.

Ownership is registered in `assist/manifest.json` at the repository root. Run `npm.cmd run check` from the root for repository validation.
